# Projeto FocaAí

## Nome
Claudio Martins Camilo

## Conceito de Design

A interface foi projetada utilizando os princípios de Calm Technology, reduzindo estímulos visuais, utilizando espaços em branco e destacando apenas as informações essenciais.

## Fluxo de Usuário

1. Usuário abre o aplicativo.
2. Configura os aplicativos bloqueados.
3. Escolhe ambiente e duração do foco.
4. Entra em uma sala de foco em grupo.
5. Finaliza a sessão.
6. Consulta o relatório de tempo ganho.

## Escolha dos Componentes

Foi utilizado um slider para seleção do tempo de foco por ser mais rápido e intuitivo do que a digitação numérica.
